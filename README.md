# 🧠 Crypto Sentiment Analyzer (NLP)

A Python-based **sentiment analysis engine** that evaluates crypto-related news and social media text using **NLTK’s VADER sentiment model**.

This project classifies text into **POSITIVE, NEGATIVE, or NEUTRAL** sentiment and provides a numerical confidence score, making it useful for **market psychology analysis** alongside technical indicators.

---

## 🚀 Features

- 📰 Analyzes crypto news headlines or social media text
- 🧠 Uses **VADER (Valence Aware Dictionary)** for sentiment scoring
- 📊 Returns both sentiment label and compound score
- ⚡ Lightweight and fast
- 🧩 Easy to integrate with trading or analytics pipelines
- 🔌 Ready for real-time data sources (Twitter, News APIs)

---

## 🛠️ Tech Stack

- **Python 3.8+**
- **NLTK**
